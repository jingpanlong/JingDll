景修 DLL 1.0.0
Windows 程序依赖诊断与修复工具
微信公众号：景同志    小红书：景同学

一、选择版本
JingDll.exe：单文件便携版，直接双击启动。
JingDll-Setup.exe：安装版，包含开始菜单、可选桌面快捷方式及卸载入口。
JingDll-Source.zip：完整源码、离线数据库、构建脚本和许可证。
支持 Windows 10 / 11 x86、x64，依赖系统 .NET Framework 4.8。
本构建未进行商业代码签名，Windows 可能显示未知发布者。

二、推荐使用流程
1. 在“程序依赖诊断”中选择报错程序的 EXE，点击“开始诊断”。
2. 选中诊断结果查看候选路径、架构、缺少导出函数及建议。
3. MSVCP140 / VCRUNTIME140 等问题：进入“官方运行库”，按程序架构安装 x86 或 x64 包。64 位系统的 32 位程序需要 x86 包。
4. DirectX 或 .NET 问题：使用对应官方页面选择应用要求的组件版本。
5. Windows 系统组件损坏：进入“Windows 修复”，先检查或执行完整系统修复。执行前展示命令并请求管理员授权，实时输出在独立任务窗口显示；等待结束再关闭任务窗口。
6. 应用私有 DLL 缺失或不兼容：关闭目标程序，选中该依赖，从原软件的可信安装包提供同名 DLL，点击“从可信文件修复选中 DLL”。工具检查架构与必需导出函数，显示来源、目标和签名，再备份并部署。
7. 如需撤销应用 DLL 替换，在“备份与回滚”选中记录回滚。目标文件已被其他程序改动时会拒绝覆盖。
8. 可导出诊断 CSV、文件详情、数据库检索 TSV 和操作日志。

三、数据库到底包含什么
内置 24,099 条离线索引记录，覆盖 10,158 个独立 DLL 名称。
Windows 实际文件元数据与 Winbindex 历史名称索引合并；同一个 DLL 的多个版本/架构分别作为记录，独立名称不重复计数。
Winbindex 补充名称未附版本/架构时明确显示“未标注”。历史或可选组件不意味着当前系统缺少它。
数据库不包含 7000 个微软或第三方 DLL 二进制文件，不是任意 DLL 自动下载服务。实际修复通过 Windows 官方工具、官方运行库，或用户提供的可信软件原始 DLL 完成。

四、诊断和修复范围
扫描为直接导入及延迟导入的静态分析，候选路径不代表 Windows 最终实际加载的文件。
动态 LoadLibrary、P/Invoke、完整托管程序集绑定、SxS 和应用自定义加载设置可能需要进一步排查；不能保证修复所有程序错误。
导出函数齐全不保证运行语义和 ABI 完全兼容，应使用原软件相同版本的文件。
Windows KnownDLLs 与 API Set 不允许通过应用目录替换。Windows、Program Files、工具数据目录及符号链接/目录联接中的文件也不支持私有 DLL 替换，请使用软件官方安装器或 Windows 修复。
Windows 系统修复与运行库安装不纳入本工具的文件回滚，由 Windows 和官方安装器管理。
ARM64 只支持识别文件元数据，本产品未在 ARM64 Windows 上验证。

五、日志、备份和隐私
数据保存在 %LOCALAPPDATA%\JingDll，包含日志、修复记录、原始备份和下载的官方安装包。
不会自动上传扫描文件和日志。官方组件下载、外部说明页及 Windows 修复可能联网。
导出的日志与报告可能含本机路径，分享前请检查。
卸载程序会保留个人备份及日志。
